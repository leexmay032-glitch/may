Claude Pro 图谱解析向导

免费 Pro 方案
1
复制下方解析提示词
点击"复制提示词"按钮，将以下提示词复制到剪贴板。
2
在 Claude.ai 中解析
前往 claude.ai，新建对话， 上传你的图片，粘贴提示词后发送。
Claude 会返回一段 JSON 代码，全选并复制全部内容（包括 { } 大括号）。
3
粘贴 JSON，导入画布
将 Claude 返回的 JSON 粘贴到下方文本框，点击"导入图谱"。
